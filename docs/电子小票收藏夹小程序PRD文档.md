## 一、产品概述

### 1\.1 产品背景

纸质小票易丢失、褪色、破损，用户日常消费、报销、生活纪念小票难以长期留存；个人用户需要一款纯私密、无社交、无信息泄露风险的小程序，实现小票快速录入、分类归档、事件整合、数据统计与便捷导出，满足小票收藏、报销记账、消费记录等核心需求。

### 1\.2 产品定位

**纯个人私密电子小票管理工具**，聚焦小票数字化收藏、分类、事件整合、统计、导出核心场景，全程无用户社交互动、无公共数据分享、无第三方数据上传，保障用户小票数据绝对隐私安全，适配个人开发者轻量开发、快速上线。

### 1\.3 目标用户

- 有小票收藏、消费记账习惯的个人用户

- 日常需要报销、留存消费凭证的职场人

- 重视个人数据隐私，拒绝信息泄露的用户

- 喜欢记录生活、留存消费纪念小票的用户

### 1\.4 核心价值

1. 纸质小票数字化，永久留存不丢失

2. 纯本地 \+ 私有云存储，100% 保障数据隐私

3. 轻量化操作，快速分类、统计、生成事件

4. 多格式导出，满足报销、打印、备份需求

5. 无社交、无广告、无多余权限，极简使用

### 1\.5 核心禁忌（个人开发者合规红线）

- 无任何用户社交功能（无好友、无分享、无广场、无互动）

- 无强制用户注册、无手机号 / 身份证等敏感信息收集

- 无小票数据公共上传、无第三方数据共享

- 无多余权限获取，仅申请核心功能必要权限

## 二、产品功能规划

### 2\.1 核心功能模块

#### 模块 1：小票录入（基础核心）

1. **拍照录入**

    - 调用 `wx.chooseMedia` 相机拍摄小票，sourceType: ['camera']

    - 本地 OCR 识别（当前为 mock 模拟，1500ms 后返回随机商家/金额/商品，待接入真实引擎）

2. **相册导入**

    - 支持从手机相册选择小票图片导入（sourceType: ['album']），同步 mock OCR

3. **手动补录 / 编辑**

    - OCR 识别信息支持手动修改、补充（商家、金额、日期、商品摘要、备注）

    - 编辑后可选择分类（8 默认 + 自定义）、标签（多选）、占位图标

    - 重复小票检测：未实现（计划 V1.3）

4. **录入规则**

    - 无需登录即可使用，所有录入数据存储至 wx.Storage
    - 小票数据结构：id, merchant, amount, date, categoryId, tags, items, note, image, placeholder, color

#### 模块 2：小票分类管理

1. **自定义分类**

    - 系统默认 8 个基础分类：餐饮(cat_food)、购物(cat_shop)、出行(cat_traffic)、医疗(cat_med)、娱乐(cat_fun)、缴费(cat_bill)、报销(cat_reim)、其他(cat_other)

    - 支持用户新增自定义分类（id 格式：cat_timestamp_random），选择图标（22 个备选 PN G @3x）、颜色（8 色）

    - 支持长按自定义分类删除（默认分类不可删），删除后该分类下小票自动归入"其他"

2. **标签管理**

    - 预设 7 个标签：报销、重要、纪念、旅行、工作、生活、其他（各带主题色）

    - 录入小票时可多选标签，标签仅展示用途无筛选功能

3. **小票列表展示**

    - 首页：按创建时间倒序展示最近 12 条（组件化 ticket-card）

    - 分类页：按月分组展示（groupByMonth）

    - ticket-card 组件：缩略图 + 商家 + 相对日期 + 明细 + 金额

4. **精准搜索**

    - 支持按商家名称、商品摘要、备注文本搜索（不区分大小写）

    - 搜索逻辑位于前端 applyFilter 函数，本地执行无数据上传

    - 暂不支持金额范围、日期范围筛选

#### 模块 3：小票事件管理

1. **事件创建**

    - 选择时间段内多张小票，合并生成自定义事件

    - 自定义事件名称、时间范围（开始/结束日期）、事件封面（10 个备选 @3x PNG）、备注

    - 事件数据结构：id, name, cover, coverColor, startDate, endDate, receiptIds[], note, createdAt

2. **事件详情**

    - 点击事件贴纸展开明细：事件内所有小票列表、总消费金额、小票数量

    - 长按事件弹出 ActionSheet：编辑、导出 PDF、删除事件

3. **事件动画生成**

    - 当前为 toast 占位（"生成动画中…→动画已生成"）

    - 计划：本地生成事件小票翻页/拼接/渐显动画，仅本地预览保存

4. **事件管理**

    - 支持事件编辑（复用 event-create 页）、删除（仅取消归类，不删小票）

#### 模块 4：消费数据统计

1. **基础统计**

    - 按周 / 月 / 年统计消费总金额、小票数量、日均消费

    - 按分类统计消费占比，Canvas 2D 环图 + 图例列表

    - 消费趋势柱状图（周：周一~日 / 月：1~31 日 / 年：1~12 月），自适应高度

2. **Top 分类排行**

    - 本期内消费 Top 4 分类，带渐变进度条展示占比

3. **统计范围**

    - 仅展示当前周期内有小票的数据，无筛选功能

#### 模块 5：导出与备份

1. **多格式导出（当前均为 demo 占位）**

    - PDF 文档导出：toast 提示"已生成"（demo）

    - Excel 台账导出：toast 提示"已生成"（demo）

    - 图片合集导出：toast 提示"已生成"（demo）

    - 导出范围可选：全部 / 指定月份 / 事件或单张

    - 导出选项：是否包含备注、是否包含图片、是否加密

2. **数据备份（当前均为 demo 占位）**

    - 本地加密备份：toast "已备份到本地"（demo，仅记录 last_backup_at 时间戳）

    - 私有云备份：Modal 提示（demo，计划对接 wx.saveFileToDisk）

3. **数据恢复**

    - 回收站：删除小票软删除进入 trash[]，带 deletedAt 时间戳，30 天内可恢复

    - 从本地导入：Modal 提示（demo，计划对接 wx.chooseMessageFile）

#### 模块 6：隐私安全设置

1. **本地加密**

    - 启动密码：支持设置至少 4 位密码，开启后进入小程序需验证（密码明文存储于 wx.Storage）

    - 指纹解锁：未实现（计划评估 wx.checkIsSupportSoterAuthentication）

    - 私密小票/事件单独加密：未实现

2. **权限管理**

    - 仅申请相机、相册、本地存储权限，无位置、通讯录、麦克风等多余权限

    - 权限可随时关闭，不影响核心功能使用

    - 权限说明页面展示所有申请的权限及用途

3. **数据注销**

    - 支持一键清空所有本地小票数据（当前清空后会自动重新初始化 mock 数据，上线前需修正）

## 三、技术实现方案

### 3.1 技术栈

| 层级 | 技术选型 |
|------|----------|
| 运行时 | 微信小程序原生框架（无第三方构建工具） |
| 语言 | JavaScript (CommonJS require/module.exports) |
| 视图层 | WXML（类 HTML 模板） |
| 样式 | WXSS（类 CSS，rpx 单位，CSS 变量） |
| 状态管理 | Page 级 this.setData()，无全局 Store |
| 数据持久化 | wx.getStorageSync / wx.setStorageSync（纯本地） |
| 图像处理 | wx.chooseMedia、wx.previewImage |
| Canvas | Canvas 2D API（环图渲染） |
| 导航 | wx.navigateTo、wx.switchTab、wx.navigateBack |
| 基础库 | ≥ 2.30.0（project.config.json 配置） |

### 3.3 数据模型

| Storage Key | 类型 | 说明 |
|-------------|------|------|

## 四、产品流程设计

### 4\.1 小票录入流程

打开小程序→拍照 / 相册导入→mock OCR 识别→手动编辑信息→选择分类 / 添加标签→选择占位图标→保存至本地→录入完成

### 4\.2 事件创建流程

首页进入事件管理→新建事件→填写事件信息→选择关联小票→确认生成→事件详情查看→生成动画（当前 toast 占位）

### 4\.3 导出流程

选择小票 / 事件→选择导出格式（PDF/Excel/图片）→demo toast 提示完成→（待真实实现）

### 4\.4 数据备份流程

进入设置→数据备份→选择备份方式（本地/个人云）→demo toast 提示完成→（待真实实现）

## 五、产品原型页面（极简页面，适配小程序）

### 5.1 首页（pages/index）

1. 顶部品牌区："小票日记" slogan + 吉祥物图标
2. 搜索框：按商家名称 / 商品摘要 / 备注文本搜索
3. 录入入口 + 本月概览卡：本月合计金额、笔数、日期
4. 快捷分类：展示前 6 个分类，点击跳转至分类页并高亮对应分类
5. 最近小票列表：按时间倒序展示（组件化 ticket-card）
6. 浮动添加按钮（FAB）位于右下角

### 5.2 分类页面（pages/category）

1. 横向滚动分类导航条：全部 + 各分类 chip + 新建按钮
2. 分类汇总列表：每个分类显示小票数量、合计金额
3. 按月分组小票列表（当前选中分类下的）
4. 新建分类弹窗：名称、图标（22 个备选）、颜色（8 色）
5. 长按自定义分类可删除（默认分类不可删），删除后该分类小票归入"其他"

### 5.3 事件页面（pages/event）

1. 事件贴纸卡片列表：名称、日期范围、小票数量、合计金额、封面图标
2. 点击事件展示明细：事件内所有小票列表、总消费、总笔数
3. 长按事件弹出菜单：编辑、导出 PDF、删除
4. "生成动画"按钮（当前为 toast 占位）

### 5.4 统计页面（pages/stats）

1. 周 / 月 / 年范围切换标签
2. 总览卡：范围消费总额、笔数、日均消费
3. 分类占比环图（Canvas 2D）+ 图例列表（分类、占比%、金额）
4. 消费趋势柱状图（周：周一~日，月：1~31 日，年：1~12 月）
5. 本期 Top 4 分类（带进度条）

### 5.5 我的页面（pages/mine）

1. 用户信息卡 + 数据小卡：小票数、事件数、回收站数
2. 数据与备份菜单：导出与打印、数据备份、回收站
3. 隐私与设置菜单：隐私设置、通用设置、隐私协议
4. 关于小票日记、清空所有数据

### 5.6 子页面

- **录入编辑页（pages/add）**：三步流程（选择来源 → OCR 扫描模拟 → 编辑保存），支持拍照/相册/手动录入，选择分类、标签、占位图标
- **小票详情页（pages/detail）**：纸张风格展示，复制、编辑（占位）、导出、删除操作
- **事件创建/编辑页（pages/event-create）**：事件名称/时间/封面/备注 + 选择关联小票列表
- **导出与备份页（pages/export）**：导出范围/格式选择 + 本地/云备份入口（demo 占位）
- **设置页（pages/settings）**：启动密码、权限说明、自动备份/图片压缩开关、主题外观选择、数据清空

### 5.7 底部导航（自定义 tabBar）

采用 `custom: true` 的自定义 tabBar，包含 5 个 slot：
- 首页（图标 tab/home）
- 分类（图标 tab/category）
- **居中添加按钮**（"+"，navigateTo add 页，非 switchTab）
- 事件（图标 tab/event）
- 我的（图标 tab/mine）

> 注意：底部导航实际为 5 项（含居中动作按钮），而非 4 项标准 tab。
